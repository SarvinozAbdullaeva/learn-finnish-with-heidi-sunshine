# Learn Finnish with Heidi (Sunshine version)

Navy and yellow "midnight sun" design with animated sun, stars, word marquee and scroll effects.

## Files
- `index.html` – the page content
- `css/style.css` – all styling and animations
- `js/script.js` – stars, greeting rotator, flashcard, menu, scroll reveal

## Run on your computer
Double-click `index.html`, or run `python3 -m http.server 8000` in this folder and open http://localhost:8000

## Go live (GitHub Pages)
Push the folder to a public GitHub repository, then Settings > Pages > Deploy from a branch > main > /(root).

## Before launch
- Replace the placeholder prices, About text and course names
- Connect the signup form and the Enroll buttons
- Remove the `noindex` line in `index.html`
